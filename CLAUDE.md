# Greatness Bot — правила для Claude Code

Discord-бот гильдии **Greatness** (AION 2, Where Winds Meet) + веб-панель (сайт) `https://greatness-bot.duckdns.org`.
Владелец и единственный разработчик — Олександр (Apostall107). Общается **по-русски**, коротко и по делу.

## Стек и структура
- **C# .NET 8**, Discord.Net 3.20, ASP.NET Core minimal API (`Web/`), хостинг — systemd на Debian VPS.
- `Program.cs` — регистрация сервисов (DI) и запуск.
- `Models/` — модели (LFG: `LfgGroup`, `Slot`, `ReserveEntry`, `LfgDraft`…).
- `Modules/` — Discord-взаимодействия (кнопки, меню, модалки, слеш-команды). `LfgModule` — с `[RequireContext(Guild)]`; кнопки из ЛС — в `LfgDmModule`.
- `Services/` — логика и хранилища (`*Store.cs`), фоновые сервисы (`BackgroundService`).
- `Web/PanelApi*.cs` — API сайта; `Web/wwwroot/app.js` + `app.css` — весь фронтенд (vanilla JS SPA, без фреймворков и сборки).
- Данные — `data/*.json` (на сервере `/opt/greatnessbot/data`), в git **не** коммитятся.

## Сборка, проверка, деплой
- Сборка: `dotnet build -c Release` (должна проходить без ошибок и предупреждений CS).
- JS: `node --check Web/wwwroot/app.js`.
- Деплой: `deploy-from-pc.bat` (сам делает `git pull`, собирает и обновляет сервер по SSH). Запускает владелец.
- Логи сервера: `journalctl -u greatnessbot` (владелец присылает скриншоты).

## Чего нельзя (защиты, которые уже есть — не обходить)
- **Не трогать и не выводить** `github-recovery-codes.txt` и любые токены/пароли (`appsettings.*.json`, `Discord:Token`).
- Хранилища читают данные только через `DataFiles.Load<T>()` и пишут через `DataFiles.Save()` (восстановление из бэкапа, защита от перезаписи повреждённых файлов). Новое хранилище — так же.
- Автоматические действия бота (забыть панель, закрыть сборы/тикеты, снять роли, удалить комнаты) — через `SafetyValve.Allow/AllowBatch`, и только при `GuildCache.Loaded(guild)`. «Канал/сообщение не найдено в кеше» ≠ «удалено»: забывать только когда Discord явно сказал `UnknownMessage/UnknownChannel` или пришло событие удаления.
- Изменения поста сбора — только через `LfgSignupService.RefreshPostAsync(group)` (очередь правок), не редактировать сообщение напрямую.
- Ответ на взаимодействие Discord — в течение 3 секунд: если дальше идёт медленная работа, сначала `DeferAsync()`.
- Тексты, которые видят участники в Discord, — через `Tx.Get(guildId, "key")` + запись в `BotTextCatalog` (редактируются на сайте в Bot texts), не хардкодить.
- Права на сайте: эндпоинты под `Require(PanelPermissions.X)`; организатор группы или владелец бота — `BotOwner.CanManage(group, userId)`.

## Сайт (frontend)
- Хелперы: `h()`, `icon()` (только иконки, которые есть в `icons.js`), `gApi`, `act`, `toast`, `store`, `statCard`, `dialog()`.
- `p.muted` автоматически превращается в подсказку «?» (`tidyHints`) — для видимого текста использовать `div`.
- После изменения в группе вызывать `refresh()` — он перерисовывает только изменённые строки карточки (`patchCard`), страница не прыгает.
- Интерфейс сайта — на английском; страница «нет доступа» — на украинском.
- Проверять вёрстку и на узком экране (телефон).

## Посты и тексты для гильдии
- Новостные посты — **на украинском**, с **разметкой Discord** (`##`, `###`, `-`, `**`, `>`, `-#`), в блоке кода, чтобы скопировать как есть.
- Ссылку на сайт ставить строкой под заголовком: `-# 🌐 [Bot Website](https://greatness-bot.duckdns.org)` (ссылки внутри `##` Discord не делает кликабельными).

## Как работать
- Перед правкой — прочитать нужный код; изменения точечные, без переписывания файлов целиком.
- После изменений — собрать (`dotnet build`), для фронта — `node --check`, коротко отчитаться по-русски: что сделано, где это на сайте/в Discord, что проверить.
- Если задача неоднозначна — короткий вопрос, а не догадка.
